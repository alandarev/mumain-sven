# Munolith master skill tree

Open Master from the menu or press A on a master character. Munolith shows all
three branches in one centered panel. Gold outlines mark learned skills; muted
icons remain locked and bright icons are available under the native requirements.
Badges show current / maximum level. Hover a skill for its description, next value
and requirements, or hover EXP for the exact experience totals.

Click a skill to use the existing upgrade confirmation; Cancel spends no points.
Close with the corner button, A or Escape. The whole tree fits the available
workspace when resolution or UI scale changes. Legacy and Modern retain their
full-screen presentation.

Verification uses injected class/skill states and native cancellation on a
disposable client. It does not establish successful server point spending.
