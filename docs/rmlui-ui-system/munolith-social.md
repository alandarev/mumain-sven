# Officer desk social windows

The Munolith social family uses the selected Officer desk layout. Guild information
keeps its emblem, name, score, membership and rival summary beside the active
Guild, Members or Alliance tab. Member and alliance lists scroll independently
of their action buttons. Party shows all five members with native HP and locations;
the combat HUD arranges them in two columns. Guild creation keeps its native
welcome, name/emblem editor and review steps, with a complete 8×8 grid and a
four-column palette of all sixteen native colors.

## Ownership and input

The native models remain authoritative for membership, roles, permissions, HP,
locations, marks and requests. Tabs queue native selection; row selection keeps
native member/alliance identity. Party leave/remove retains its original immediate
request behavior. The roster and HUD share the native leader/self authorization
check. Guild rank removal also rechecks master authority.

Munolith declares window scaling and header dragging in a dedicated social
workspace group. It fits the open social panels together without applying the
older dock region's height fit a second time.
Native Party target areas and emblem painting/erasing read resolved document
anchors, so changing theme geometry or scale moves input with the visible cells.
Legacy and Modern retain their existing fixed geometry fallbacks. Empty mark cells
are transparent; Munolith uses the actual guild texture palette, while the legacy
editor's historical color conversion is retained.

The existing guild packet/model has no populated creation date, so the draft's
sample date is omitted. Native localized labels and actual server data replace
illustrative draft text. This change adds no guild or party protocol.

## Verification

Layout tests exercise the complete editor/palette, review/back retention,
two-column HUD target anchors and HP fractions, persistent Guild identity, member
selection, scrolling and permission-controlled actions. Native evidence is kept
in the workspace's social UI receipt, including scale/resize, theme compatibility
and fixture cleanup. These presentation fixtures do not certify server guild
creation, promotion, expulsion, disbanding or Party transactions.
