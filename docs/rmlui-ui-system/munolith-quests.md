# Munolith quests

The Quest journal keeps the active quest list beside the selected quest's details.
Select a quest on the left to see its summary, requirements and rewards on the
right. Each pane scrolls independently when needed. Start uses the existing
quest eligibility; Give up retains its confirmation dialog. Change Class and
Castle/Temple remain separate tabs.

NPC dialogue and both quest-progress screens share the same silver/stone frame,
compact page arrows and corner close control. A long NPC response list scrolls
inside its pane. Reward colors distinguish unmet requirements and ordinary or
random rewards. Click an item reward to inspect it; completion retains the
original requirement check. Escape closes the active window or confirmation.

All four screens use Munolith's shared window scale and workspace fitting.
Their presentation does not change quest rules or rewards. Legacy and Modern
keep their own documents and appearance. The older NPC quest screen also uses the matching frame, bounded dialogue and
response panes, wrapped requirements and live condition-item models. Its original
Zen cost and eligibility checks remain in force.

The native presentation checkpoint exercises injected populated states, paging,
selection, confirmation cancellation, item inspection, scales and closing. It
does not establish successful server quest acceptance, progression or completion.
