# Munolith command workbench

The400x400 fitted desk shows the complete native catalog and templates in a bounded scrolling pane. Descriptions and parameter rows flow in that pane. One named native value field appears above the persistent footer while editing; native numeric filtering, accepted-value cycling and stepwise Escape remain authoritative.

Existing Legacy/Modern20-row slices remain available. Both sliced and complete entries carry absolute row indices, so scrolling cannot select or remove a different command/template. Munolith wheel input scrolls RmlUi without also moving the native slice; Up/Down use the resolved row box. Page changes reset the scroll pane like the native slice.

Favorites, save/remove templates, Execute and Close reuse native actions. Selecting a command with no parameters still executes immediately; selecting a template still executes it. The presentation does not introduce confirmation or permission changes. Native QA uses synthetic parameter commands and unsent fields.
