# Shared dialogs in Munolith

Confirmation and message windows use matching silver/stone frames and green/gold controls. Native warnings, item/portrait previews, text entry, shuffled numeric keypads, progress bars and every native action remain available. Confirmation chrome draws behind item previews.

Tall confirmations center in the viewport and long text can scroll. Native cancel and guard behavior stays unchanged, including the independent password-saving confirmation. Legacy and Modern retain their original presentation.

Residual shared native message boxes use a matching green/gold frame, gold progress and flat controls. Native text colors, frame dimensions, callback indices, jewel rows and lettered OK artwork remain intact. Specific correspondence and result dialogs keep their dedicated layouts.
