# Munolith travel, commands and Gens desks

Theme documents reuse the existing native models and callbacks. Travel has a wider destination lane, level/cost columns and native height geometry, with a readable physical row floor and RmlUi wheel scrolling. Unavailable rows retain native guards; reachable row clicks still execute the native warp action.

Commands retain all twelve choices in order, visibly mark the armed command, and use native Close/Escape cancellation and target overlays. The Special Commands choice opens the existing command editor.

Gens retains family/rank insignia, title, contribution and complete promotion/reward notes in a bounded scrolling area. The original atlas is explicitly linked. Command/Gens headers drag their independently fitted workspace groups.

No protocol, permissions, transactions or server data changes.

## Map and location controls

Press Tab to open the full-screen map. Its legend identifies your arrow, NPCs and
portals; hover a marker for its native name. Tab, Escape and the corner control
close the map. The location strip retains Helper configuration and start/stop
controls; hover its readout or buttons for the full location and action hints.
Map-arrival artwork uses a matching frame while retaining its native fade.
