# Munolith context and reference help

The player context menu retains its native target, five actions and112×140
footprint. Green/gold chrome and selected-row feedback follow native hit intervals:
rows begin at38 and advance20 reference pixels. Action dispatch remains native.

Item-level and set-option local help tables use matching green fills and gold
borders while preserving native measurements, fonts, content and semantic colors.
These windows are separate from Armory's item hover tooltip. Escape/F1 retain
native Close behavior.

Item-level spacer construction uses wide spaces instead of byte memset. Set
reference formatting uses the decoded extended/full option values rather than
option IDs. Neither correction changes item statistics or set-bonus calculation.

Munolith centers each passive reference table through its measured native fill
bounds, avoiding the Dialog transform's negative origin at small/high-scale
viewports. Other themes retain their original placement.

The reference-foreground markup capability puts these passive cards on the
existing foreground-panel layer above the compact HUD. Other themes preserve
their native reference layers.
