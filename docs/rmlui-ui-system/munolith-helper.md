# MU Helper setup desk

Munolith gives the Helper a wider settings desk with Hunting, Obtaining and Other
tabs. Recovery and skill conditions open a compact companion; attack and buff
slots open a scrollable library showing each eligible learned skill's name and
original icon. Custom loot names have a separate scrolling list.

The panels fit together and share a draggable header position. Escape closes a
skill picker or detail companion before its owner. Right-click clears a skill
slot as before. The existing class rules determine recovery, Party support,
combo and Dark Raven controls. Gauge thresholds and interval fields retain their
native limits. Detail Save updates staged settings; the main Save Setting action
keeps the existing persistence behavior. Closing without it does not submit a
settings change.

Legacy and Modern retain their own configuration/detail layouts and the original
skill fan-out. The native skill filter and current learned-skill list validate
library choices. This presentation change does not alter Helper automation,
combat, pickup rules or the network protocol.
