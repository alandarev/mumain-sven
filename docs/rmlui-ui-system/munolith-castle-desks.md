# Castle desks in Munolith

The Senior NPC uses a larger defense map beside the selected gate or statue's durability, defense and next upgrades. Select any native map icon to inspect it. Repair and improvement controls keep the game's existing availability checks and confirmations. Tax rates, treasury and complete rules share a scrolling page; Apply and Withdraw remain accessible below it. The native Store tab opens castle senior crafting.

The Guard NPC keeps the owner summary above Status, Announce/Register and List. Registration and siege tables scroll to every available row, retain native guild permissions and highlight the selected guild. Siege score stays below the list. Registration availability follows the current siege period and character/guild eligibility.

Both desks fit the available viewport, retain readable text at smaller sizes and can be dragged by their title. Close and Escape retain native behavior. These are presentation changes; server siege support and economics are unchanged.
