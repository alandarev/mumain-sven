# Munolith settings and reference

Options uses a 420 by 330 dp framed desk with six native tabs, aligned labels and
controls, bounded dropdown overlays and scrolling tab content, and fixed Close. Its native callbacks,
gauge math, drag, click-through protection and setting persistence are unchanged.

F1 Help uses the original semantic key/chat lines and native font sizes in a
bounded scrollable reference overlay above the measured HUD. The theme owns width and row flow. F1
cycles the native pages and closes; Escape closes either page. The footer shows
those keys. Other themes retain their own presentation.

## Pet details
The Pet panel opens alongside Character. Horse and Raven tabs group native level, life, experience and combat stats; the life bar shows the current fraction. Raven commands are a passive icon reference with complete labels. Tabs change the displayed pet; Close dismisses the panel.

The full-screen map continues behind the compact HUD, including the gaps around its controls. Individual slot frames, resource crystals and progress bars remain visible.
