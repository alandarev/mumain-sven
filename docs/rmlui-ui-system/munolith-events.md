# Munolith event entry

Blood Castle and Devil Square use compact level desks. The available band is
highlighted; other bands remain disabled. Descriptions and the level list scroll
when needed, with Close always available below them.

Doppelganger and Imperial Guardian show the native entry-ticket preview between
the requirements and status/warnings. Their original Enter and Close actions
remain. Doppelganger's waiting period still locks entry; Imperial Guardian retains
its party and Sunday ticket requirements.

Illusion Temple shows the minimum-level notice or all six bands, highlights the
player's eligible band and displays the live member count. Enter remains subject
to the game's eligibility rules. Kanturu shows its current battle/refinery state
and notes above the native Refresh, Enter and Close controls.

These entry windows fit above the HUD and share Munolith's silver/stone frame.
Scroll long content, drag a header to move the entry group, or use Escape/Close to
leave. The theme does not change event availability, tickets or server admission.

## Illusion Temple results
The result panel separates camp, character, class, experience and points into columns. Blue/gold rows identify the teams and a gold band marks your character. The roster scrolls when needed. Victory/defeat artwork fades in above the table; the native compensation hint remains beside Close, which retains its reward-request behavior.

## Crywolf
A compact status card groups the five altar indicators, statue shield, Dark Elf count, Balgass health and native countdown. On narrow windows the card moves above the compact HUD. The result overlay retains the native success/failure, rank and experience artwork over a matching green/gold backing. All overlays remain passive.

Illusion Temple matches use a single tactical card for the event skill, required and earned kill points, map and countdown. The native arrow buttons select the event skill; the map button cycles transparency. Scoring retains each team’s coloured digits and badge, and tutorial steps wrap in a separate card.
