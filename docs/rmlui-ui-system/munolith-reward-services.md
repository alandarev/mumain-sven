# Reward services in Munolith

Lucky coin registration shows the rotating native coin, registered count and complete event notes. Registration retains the native button lock and request. Lucky coin exchange presents all10/20/30 choices and the warning that exchanged coins cannot be returned. These coin actions execute immediately as before.

Lucky-item trade and refinery use the native8x4 material grid above complete scrolling rules and result information. Combining/Refine retains the native recipe checks and confirmation. Both Close controls use the existing occupied/held-item guard, so materials must be returned to Inventory before closing.

Each service stays in the native Inventory companion group. Either title can drag the group; its fitted size adapts to the safe viewport and UI scale. Native item previews, ownership and economic rules remain unchanged.
