# Frontend in Munolith

The server browser presents server groups and their native load/availability information in a two-column desk. Login uses the same silver/stone frame with aligned account/password fields, native Remember me/Save password options and the original actions. Passwords retain the game's masking and storage choices.

The login bar labels Menu and Credits directly. Character selection labels Create, Menu, Connect and Delete with their original availability and confirmation flows.

Character-list labels hide while the creation desk is open and return on cancellation. Character creation keeps its live3D preview alongside every native class, its base attributes, description and name entry. Locked classes keep their native account restrictions. Focused Escape uses Cancel, and the open desk blocks clicks on the character bar below it. Cancel leaves the account unchanged; creation, deletion and authentication rules stay native. Legacy and Modern retain their original presentation.

The frontend System Menu uses a centered green/gold card. Login hides Select Server; character selection keeps it available. Options and Close retain their native actions, and Escape closes the menu. Its backdrop blocks the scene controls below it.

The login overlay keeps its native logo animation and places supplied version/copyright/rights text in a padded footer. The footer is passive and disappears when character selection is entered.
